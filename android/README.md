# Monkey VPN — Android (APK)

Приложение для Android на открытом ядре [Xray-core](https://github.com/XTLS/Xray-core), собранное вручную (без Gradle/студии).

## Установка

1. Перекинь файл **`MonkeyVPN.apk`** на телефон (USB/Telegram/Drive).
2. Открой файл на телефоне → «Установить».
3. Android может спросить «разрешить установку из этого источника» — подтверди.
4. Открой приложение **Monkey VPN**.

*Это неподписанный Play-ключом APK — ставится как «неизвестный источник», это нормально для личной сборки.*

## Как пользоваться

1. Вставь ссылку на подписку Monkey VPN → «Загрузить».
2. Выбери сервер → «Подключить».
3. Приложение запустит ядро Xray:
   - SOCKS5: `127.0.0.1:10808`
   - HTTP: `127.0.0.1:10809`

## ⚠️ Важное ограничение v1.0

Это приложение поднимает **локальный прокси**, но не перехватывает весь трафик телефона (это требует VpnService + tun2socks, может появиться в v1.1). Пока:

- **Firefox**: Настройки → Настройки сети → Ручная настройка → SOCKS `127.0.0.1:10808`, порт `10808`, галочка «Отправлять DNS через SOCKS».
- **Telegram**: Настройки → Данные → Прокси → SOCKS5 `127.0.0.1:10808`.
- Для «всего трафика сразу» рекомендуем реш構ение: v2rayNG (Play/Releases) — вставь туда ту же ссылку подписки Monkey VPN.

## Сборка из исходников

```
powershell C:\Users\user\MonkeyProj\build.ps1
```
Проект собирается из пути `C:\Users\user\MonkeyProj` (aapt2 не работает с кириллицей в путях).

## Структура

- `src/com/monkeyvpn/MainActivity.java` — весь код приложения (UI + парсер подписки + запуск ядра)
- `AndroidManifest.xml` — манифест
- `jniLibs/` — ядро Xray arm64 + x86_64
- `assets/` — geodata (geoip.dat, geosite.dat)
- `build.ps1` — скрипт сборки (javac → d8 → aapt2 → zip → apksigner)
