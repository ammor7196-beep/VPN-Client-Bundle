# Monkey VPN (Xray)

Простое Windows-приложение для VPN-сервиса на открытом ядре [Xray-core](https://github.com/XTLS/Xray-core) (проект V2Ray).
Никаких установок не нужно — всё уже в папке.

## Как пользоваться

1. Запусти **`Запуск VPN.bat`** (двойной клик).
2. Вставь в поле **ссылку на подписку Monkey VPN** и нажми **Загрузить**.
3. Выбери сервер в списке (или двойной клик по нему) и нажми **Подключить**.
4. Готово! Через пару секунд в статусе появится твой новый IP и страна.

Кнопка **Отключить** останавливает VPN и снимает системный прокси.
Также при закрытии окна приложения всё автоматически отключается.

## Что поддерживается

Протоколы (ссылки vmess://, vless://, trojan://, ss://):
- vmess (+ TLS, ws/grpc/http/tcp)
- vless (+ TLS, REALITY, ws/grpc/http/tcp, flow)
- trojan (TCP, TLS)
- shadowsocks (SIP002 и classic)

## Как это работает

Ядро Xray поднимает локальный прокси на твоём компьютере:
- SOCKS5 `127.0.0.1:10808`
- HTTP `127.0.0.1:10809`

Кнопка «Подключить» автоматически включает системный прокси — весь трафик браузеров и большинства приложений пойдёт через VPN.

### Если у программы нет своего прокси
Программы с собственными настройками прокси (например, некоторые игры) нужно настроить вручную на `127.0.0.1:10808` (SOCKS) или `127.0.0.1:10809` (HTTP).

## Файлы в папке

- `app.ps1` — код приложения
- `Запуск VPN.bat` — запуск
- `Core/xray.exe` — открытое ядро Xray
- `settings.json` — сохранённая ссылка на подписку и последний сервер
- `config.json` — конфиг, который сейчас используется
- `xray.log` — лог последнего запуска ядра (смотри при ошибках)

## Важно

- Приложение поднимает локальный прокси и включает системный прокси — весь трафик браузеров пойдёт через VPN. Для программ с собственными настройками прокси укажи вручную `127.0.0.1:10808` (SOCKS5) или `127.0.0.1:10809` (HTTP).
- VPN не делает тебя анонимным на 100% — не используй его для чего-либо противозаконного.

## Проблемы и решения

Если при подключении возникает ошибка, открой `xray.log` и `xray-err.log` — там текст ошибки от ядра. Также можно очистить файлы и попробовать снова.
